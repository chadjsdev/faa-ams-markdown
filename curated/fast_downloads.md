# fast.faa.gov manual download checklist

fast.faa.gov's robots.txt disallows all automated crawlers, so these are
downloaded by hand. Click each link, save the file into `inbox/`, and keep the
original filename (that's how `convert.py` maps a file back to its source URL).

For `.cfm` pages: open in your browser, then File > Save Page As >
"Webpage, HTML Only" into `inbox/`. Keep the default filename.

Add any links you find to this file; `convert.py` reads every URL here.
