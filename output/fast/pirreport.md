# PIR Process

## Purpose of the PIR

The PIR for the {*insert program name*} will assess actual program results against baseline expectations to determine whether:

* Program costs, performance, schedule, and benefits targets are being achieved.
* The FAA got what it asked for; and if not, why not?
* The investment is providing the service the customer needs; and if not, what can we do to improve service?
* There are systemic problems that need to be fixed before widespread deployment.
* There are any lessons learned about the acquisition management process.
* The business case is still valid.
