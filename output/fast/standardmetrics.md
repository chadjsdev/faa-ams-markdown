***Acquisition Management System Guidance***

**Program Performance Metrics**

**July 2023**

**Program Performance Metrics**

Service organizations submit status monthly for the program performance metrics via the Strategic Planning Implementation Reporting and Evaluation (SPIRE) web-based management tool using a color code of green, yellow, or red. The program metrics are organized into the following categories: cost, schedule, performance, variance drivers, resources, external interest and program manager assessment.

**Cost Metric Assessment**

The Cost Metric Assessment is based on the supporting indicators in the table below. Program Offices (PO) assess each indicator in its relation to projection of the overall Cost Variance at Completion (CVAC). The CVAC is determined by the PO entering the program’s Estimated Cost at Completion (ECAC). The ECAC will drive the Cost metric. The CVAC supporting indicator may or may not apply to Execution Plan (EP) programs, depending on the EP type.
